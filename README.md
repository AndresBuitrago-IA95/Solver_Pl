# Software PL (Programación Lineal)

Este proyecto es una aplicación web para resolver y analizar problemas de Programación Lineal (método Simplex, Análisis de Sensibilidad, Método Gráfico).

## Estado del Proyecto: Sprints

A continuación se detalla el progreso del proyecto dividido en 3 Sprints:

### ✅ Sprint 1 - Realizado
- **Configuración del proyecto**: Creación de la estructura base del proyecto (`index.html`, `index.css`).
- **Interfaz de usuario básica**: Desarrollo del frontend para la entrada de datos (`ui.js`).
- **Lógica Simplex Base**: Implementación inicial del algoritmo Simplex para la resolución de modelos de programación lineal (`simplex.js`).
- Captura de la función objetivo y configuración de restricciones (<=, >=, =).

### ⏳ Sprint 2 - Pendiente
- **Análisis de Sensibilidad**: Implementación detallada de la lógica para el cálculo y visualización del análisis de sensibilidad (`sensitivity.js`).
- **Mejoras en el Algoritmo Simplex**: Soporte robusto para casos especiales (dos fases, penalización, degeneración).
- **Pruebas y validación**: Ejecución de casos de prueba integrales para asegurar la precisión matemática (`test.js`, `_test_combined.js`).

### ⏳ Sprint 3 - Pendiente
- **Método Gráfico**: Implementación y visualización del método gráfico para problemas de 2 variables (`graph.js`).
- **Mejoras UI/UX**: Refinamiento estético, diseño responsivo y retroalimentación visual amigable (alertas, manejo de errores).
- **Despliegue y Documentación**: Revisión final, limpieza de código y publicación de la aplicación para los usuarios finales.
